# Contributing
Thanks for your interest in contributing to Beryl!

## Reporting Bugs & Requesting Features
For reporting bugs and requesting features, opening an [Issue](https://github.com/Beryl-Engine/Beryl/issues) is the best way to do it.

## Pull Requests
Code contributions are welcome via [Pull Requests](https://github.com/Beryl-Engine/Beryl/pulls). When working on engine changes, Beryl encourages opening a [**Draft Pull Request**](https://github.blog/news-insights/product-news/introducing-draft-pull-requests/) early in the process.

This lets you document and discuss your work before it's finished, giving the community a chance to give feedback on the approach and the included commits as they evolve.
